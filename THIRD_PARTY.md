# Third-party projects and data

CurbShade interoperates with or is conceptually built around these projects:

- NetworkX — graph algorithms. BSD-3-Clause.
- OSMnx — optional network acquisition in CurbShade-data. MIT.
- OpenStreetMap — geographic data. ODbL.
- OpenSidewalks — pedestrian-network schema/semantics. The schema repository currently carries CC BY-ND 4.0; CurbShade does not redistribute or modify that schema.
- Project Sidewalk — accessibility mapping and validation research/software. CurbShade does not redistribute its code or datasets.

Always verify the current upstream license before redistributing upstream material or derived databases.
